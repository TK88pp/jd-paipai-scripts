# jd-paipai-scripts

京东拍拍夺宝岛（1paipai.jd.com）辅助油猴脚本，两个脚本可单独使用，也可配合使用。

> ⚠️ 免责声明：仅供个人学习研究自动化技术使用，与京东官方无关。请遵守站点服务条款，自行承担使用风险。

## 安装

1. 浏览器（Edge / Chrome）安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. Edge 用户需在 `edge://extensions` 中开启 Tampermonkey 的「允许用户脚本」，并将扩展「站点访问」设为「在所有站点上」
3. 点击下方脚本链接，在弹出的 Tampermonkey 页面点【安装】：

- [jd-paipai-bidder.user.js](./jd-paipai-bidder.user.js)（抢拍助手）
- [jd-paipai-searcher.user.js](./jd-paipai-searcher.user.js)（搜索助手）

## jd-paipai-bidder.user.js — 抢拍助手（v1.1.4）

拍卖详情页浮窗，最后一刻自动出价一次（不刷接口，模拟页面操作）。

- **保守竞争出价**：出价 = 当前价 + 加价幅度（幅度 ≥1 元整数，可自定义）；心理价位为放弃线，超过即放弃
- 达到封顶价则按封顶价一口价出价
- 提前出价秒数可调（默认 1 秒）
- 状态识别：未开拍 / 竞拍中（实时倒计时）/ 已结束
- 启动时输出「元素自检」日志，显示出价输入框与出价按钮是否已定位成功

## jd-paipai-searcher.user.js — 搜索助手（v1.2.0）

夺宝岛列表页工具条（列表页本身没有关键词搜索）。

- **过滤本页**：输入关键词（多个空格分隔 = 都要命中），不匹配的商品立即隐藏，翻页自动继续过滤
- **本分类深搜**：在当前浏览的分类内自动翻页扫描（5/10/20 页可选），结果以原生卡片样式汇总展示，每张卡片标注预计结束/开拍时间
- 筛选条件：当前价上限、剩余时间、成色
- 点击结果卡片直达详情页（配合抢拍助手自动出价）
